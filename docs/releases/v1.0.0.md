# cross-agent 1.0.0

The first public release.

`cross-agent` delegates a prompt to Antigravity (`agy`), Claude Code (`claude`) or Codex (`codex`)
in headless mode, with a wall-clock timeout, rate-limit detection and an optional JSON receipt.

## Highlights

- **`agy`, `claude`, `codex`**: one bounded delegation each. A failed run whose output reads as a
  quota or rate limit exits 75 (`EX_TEMPFAIL`); a timeout exits 124. Codex always runs in a
  read-only sandbox.
- **`--json`**: one receipt with the outcome, exit code, duration, requested and launch-configured
  model and effort, a SHA-256 of the prompt, and scrubbed, length-bounded output.
- **`status` and `select`**: read-only. List each harness's models with tags, tier and subscription
  headroom, and pick one model for a task.
- **Secret handling**: the secret-surface configuration of nuvek-core loads first. An unusable file
  stops the run with exit 78 (`EX_CONFIG`) rather than running with less protection.

## Configuration

Everything has a neutral default. The delegation ledger directory (`CROSS_AGENT_LEDGER_DIR`) and the
two agy model aliases (`CROSS_AGENT_AGY_FLASH`, `CROSS_AGENT_AGY_PRO`) are set through the
environment. See `docs/configuration.md`.

## Install

```bash
cargo install --git https://github.com/jean1880/nuvek-cross-agent --tag v1.0.0
```

Or download the static x86_64 binary below and check it against `SHA256SUMS`.
